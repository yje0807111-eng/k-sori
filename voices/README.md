# voices — 목소리 넣는 곳

목소리 하나 = 폴더 하나입니다. `CV…` 로 시작하는 42명은 Mozilla Common Voice 한국어(CC0)에서 고른 공개 목소리예요([목록](목록.md)).
내 목소리를 더할 때는 **본인 또는 사용을 허락받은 사람의 녹음만** 넣으세요.

## 가장 쉬운 방법 (자동)
녹음 파일(또는 녹음이 들어 있는 폴더)을 주면 알아서 조각을 만듭니다.

```
ksori.bat add-voice 내목소리 D:\녹음\내목소리 --gender 남
```

## 직접 만들 때 폴더 모양
```
voices/
  내목소리/
    clips/          조각 wav (24kHz 모노, 2~12초)
    list.csv        file,sec,text  (조각 이름, 길이, 그 조각에서 말한 글)
    voice.json      {"gender": "남"}
```

## 좋은 목소리를 만드는 법
- 배경 음악·잡음이 없는 녹음 **5분 이상**(조각 30개 이상)
- 책을 읽듯 차분하게 말한 녹음이 나레이션에 좋아요
- `list.csv` 의 글이 실제 말과 다르면 고쳐 주세요(틀린 글은 목소리를 흐리게 해요)
- 목소리를 고치거나 조각을 바꾸면 그 폴더의 `emb_*.pt` 파일을 지우세요(평균 숫자를 다시 계산)
